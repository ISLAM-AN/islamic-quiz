# Илмхона — отдельная веб-панель администратора

Адаптивная двуязычная (таджикский/русский) панель. Включает CRUD для вопросов конкурса, каталога PDF-книг и двуязычного контента. Для каждого вопроса предусмотрены 4 варианта ответа на обоих языках, правильный вариант, сообщения об успехе/ошибке и выбор изображения/видео в качестве фона.

Откройте `index.html` в браузере. Данные хранятся локально в этом браузере. Сейчас это рабочий прототип CRUD-метаданных, а не production-система: авторизация администратора, постоянная загрузка файлов в Storage и синхронизация между устройствами требуют настройки Supabase и проверки RLS. Счётчик установок показывает «—», пока не подключён реальный источник статистики; он не подменяет неизвестное значение фиктивным числом.
