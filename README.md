# Islamic Quiz Admin — версияи ибтидоӣ

Ин лоиҳа як **оғози воқеии сайти идоракунӣ** аст: воридшавии маъмур, сохтани саволи 4-варианта, интихоби ҷавоби дуруст, паёмҳои мусбат/манфӣ, акс ё видеои замина, рӯйхати саволҳо, ҷустуҷӯ, таҳрир ва несткунӣ. API-и аввалия барои ҳамоҳангсозии барномаи Android низ мавҷуд аст.

## Чӣ лозим аст
- Node.js 20 ё навтар
- Барои ҷойгиркунии онлайн сервере, ки Node.js-ро дастгирӣ кунад
- HTTPS дар муҳити истеҳсолӣ

## Оғози маҳаллӣ
1. ZIP-ро кушоед.
2. Дар дохили ҷузвдон терминал кушоед.
3. Фармонро иҷро кунед: `npm install`
4. Файли `.env.example`-ро ба `.env` нусхабардорӣ кунед.
5. Барои сохтани hash-и рамз фармонро иҷро кунед:
   `node -e "console.log(require('bcryptjs').hashSync('RAMZI_KAVI', 12))"`
6. Натиҷаро ба `ADMIN_PASSWORD_HASH` дар `.env` гузоред. `ADMIN_USERNAME` ва `SESSION_SECRET`-ро низ иваз кунед.
7. Фармонро иҷро кунед: `npm start`
8. Дар браузер `http://localhost:3000` кушоед ва бо номи корбар/рамзи худ ворид шавед.

## Маҳдудиятҳо ва корҳои зарурӣ пеш аз нашри оммавӣ
- Ин версияи ибтидоӣ аст, на хостинги фаъол. Барои истифодаи онлайн бояд онро ба хостинги Node.js ҷойгир кунед ва диски доимӣ ё махзани идорашаванда истифода баред.
- Барои истеҳсол, session store-и доимӣ (на MemoryStore), backup-и махзан, HTTPS, маҳдудиятҳои боркунии файл, мониторинг ва сиёсати нигоҳдории маълумот илова карда шавад.
- Барои видео браузер давомнокиро ҳангоми интихоби файл месанҷад; санҷиши серверӣ бо ffprobe ё коркарди видео пеш аз нашр бояд илова шавад.
- API-и `/api/sync/questions` танҳо саволҳои нашршударо медиҳад ва ҷавоби дурустро фош намекунад. Барои истифодаи воқеии Android, ҳамоҳангсозии ҳазфҳо ва версиябандии пурраи маълумот бояд илова шавад.
- Матнҳои динӣ ва истинодҳо бояд пеш аз нашр аз ҷониби шахси донишманд санҷида шаванд.
- Файлҳои акс/видео дар `uploads/`, махзани SQLite дар `data/` нигоҳ дошта мешаванд. Ин ду ҷузвдонро мунтазам нусхаи эҳтиётӣ гиред.
