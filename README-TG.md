# Илмхона — веб-панели админ (версияи пайвастшаванда)

Ин баста дар асоси `index.html`-и фиристодаи шумо сохта шудааст. Пайвасти мавҷудаи Supabase Auth, ҷадвали `admins`, ҷадвали `questions` ва bucket-и `question-media` нигоҳ дошта шудаанд.

## Имкониятҳо
- Воридшавии маъмур тавассути Supabase Auth.
- Саволҳои мусобиқа бо матни тоҷикӣ ва русӣ, чор ҷавоб барои ҳар забон, паёмҳои ду забон, ҳолатҳои лоиҳа/нашршуда/пинҳон.
- Заминаи аксӣ ё видеои то 5 сония барои савол (то 20 MB).
- Илова, таҳрир, нашр/пинҳон ва нест кардани китобҳои PDF, бо ном/тавсифи тоҷикӣ ва русӣ, муаллиф, категория, забон ва муқова.
- Омори `app_installations` — танҳо ID-ҳое, ки худи барномаи Android сабт мекунад.
- Интерфейси адаптивӣ барои телефон ва компютер; интихоби забони панели идоракунӣ.

## Пайваст кардани база
1. Дар Supabase Dashboard-и лоиҳаи мавҷуда SQL Editor-ро кушоед.
2. Мундариҷаи `supabase/001_admin_upgrade.sql`-ро як бор иҷро кунед.
3. `index.html`-ро дар hosting-и веб ҷойгир кунед. URL-и лоиҳаи мавҷуда дар майдони Project URL пешакӣ гузошта шудааст.
4. Дар майдони Publishable key танҳо калиди publishable/anon-и лоиҳа гузоред. Ҳеҷ гоҳ `service_role` ё secret key-ро дар HTML нагузоред.
5. Ҳисоби админ бояд дар Supabase Auth бошад ва `auth.uid()`-и он дар `public.admins.user_id` сабт шуда бошад.
6. Барои саволҳо bucket-и мавҷудаи `question-media` бояд дошта бошад ва сиёсати Storage ба маъмур иҷозаи upload/delete диҳад. Ин SQL bucket-и саволҳоро қасдан иваз намекунад.

## Китобҳои PDF
- Bucket-и `islamic-books` аз тарафи SQL сохта мешавад (public-read, танҳо маъмурон upload/update/delete).
- Лимити UI: PDF то 100 MB; муқова то 10 MB.
- Феҳристи китобҳо дар `public.islamic_books` нигоҳ дошта мешавад. Барои он ки китобҳо дар барномаи Android ҳам намоён шаванд, Android бояд аз ҳамин ҷадвал китобҳои `status='published'`-ро бихонад ва файлҳоро аз Storage кушояд/боргирӣ кунад.

## Омори насбҳо — маҳдудият
Вебсайт наметавонад мустақилона шумораи воқеии насбҳои APK-ро донад. Ҷадвали `app_installations` барои ID-и тасодуфии насб пешбинӣ шудааст. Барои пур шудани омор, Android бояд дар оғози аввал ID-и устувор созад ва бо Supabase upsert/insert фиристад. Ин ҳисоб telemetry аст, на омори расман тасдиқшудаи Google Play; онро метавон сохтакорӣ кард, агар endpoint муҳофизати иловагӣ надошта бошад.

## Муҳим
- HTML бо Supabase JS аз CDN истифода мекунад; ҳангоми воридшавӣ интернет лозим аст.
- SQL migration ба схемаҳои мавҷудаи `questions` такя мекунад (`question_text`, `option_a`…`option_d`, `correct_option`, `status`, `media_path`, `media_type`, `source_text`, `success_message`, `failure_message`). Агар схема фарқ кунад, хатои SQL-ро фиристед — мувофиқ мекунем.
- Ин файл аз ҷиҳати синтаксиси JavaScript санҷида шудааст, аммо бо маълумоти воқеии лоиҳаи Supabase воридшавӣ/CRUD-и зинда аз ин муҳит санҷида нашудааст.
